# 🥁 오케이스트라 (OKAYSTRA) · 엄지 드럼

인스타 [@ok_aystra](https://www.instagram.com/ok_aystra/) 와 연결된 게임.

엄지 두 개로 하는 리듬게임. 릴스에서 보고 들어온 사람이 **설치·가입 없이 바로** 해볼 수 있게 만든 웹게임입니다.

- 콘셉트: **공연 무대 위 드럼 세트**. 마스코트 쿵콩이가 드러머로 앉아 있고, 밴드가 **누구나 아는 명곡**(작은 별, 징글벨, 캉캉, 터키 행진곡…)을 연주하면 **내가 킥과 스네어를 채워 넣는** 구조.
- 노트는 드럼 게임 관례를 따름: **킥 = 레인을 가로지르는 가로 막대**(Rock Band 방식), **스네어 = 둥근 드럼 헤드 패드**.
- 타격감: 킥은 화면 전체가 '쿵' 눌리고 베이스드럼이 부풀며 울림 링, 스네어는 스틱이 내려치고 불꽃·짧은 흔들림. 25콤보마다 크래시 심벌 + 관객 환호, 30콤보부터 GROOVE(조명 빨라짐).
- 카운트인은 드러머처럼 스틱을 머리 위에서 딱딱 치며 "1, 2, 3, 4!"
- 화면은 **원근법 길**: 줄이 저 멀리(화면 위)로 갈수록 좁아지고, 노트가 먼 곳에서 작게 나타나 점점 커지며 다가옴. 길 맨 앞(판정선)에 그 줄의 악기(크래시·킥·스네어·하이햇)가 놓여 있고, **줄 아무 데나 누르면** 그 악기가 울림 (비스듬한 줄 모양 그대로 판정). 카운트인 때 줄마다 "왼쪽 엄지 / 킥 (쿵)" 말풍선과 물결 표시.
- 곡은 **오케스트라 반주**: 진짜 악기 샘플로 연주. 멜로디 = 피아노(박자 또렷하게) + 바이올린 합주, 화음 = 현악 패드 + (곡이 달아오르면) 호른·트롬본, 베이스 = 첼로 + 절정에서 튜바, 팀파니는 마디 첫 박과 크래시 직전 롤. 곡 앞부분은 가볍게, 뒤로 갈수록 악기가 늘어나며 웅장해짐.
  - 피아노 `public/audio/piano/` (21개 · 약 420KB), 오케스트라 `public/audio/orch/` (38개 · 약 900KB, 받는 대로 중간부터 합류)
  - ⚙ 설정 → 반주: **오케스트라 / 피아노만** (데이터 아끼기). 샘플을 못 받으면 예전 합성음으로 대신 연주.
- 드럼 소리는 Web Audio 합성(킥: 서브+펀치+비터 클릭 / 스네어: 통 울림+스냅+스네어 줄 / 작은 방 리버브). 내가 누를 때만 킥·스네어 소리가 납니다.
- 결과 화면에서 별이 하나씩 뜰 때 '띵!' 효과음, 별 3개면 짜잔 화음. 박자가 한쪽으로 계속 밀리면(블루투스 이어폰 등) "내 손에 맞게 자동 보정" 버튼이 나옴.

### 친구 대결 방 · 건의함 · 업데이트 소식 (2026-11-18)

- **⚔️ 대결 방** (시작 화면 버튼, `room.js` + 서버 `server/rooms.js`): 방 만들기 → 4자리 코드(또는 `/?room=1234` 링크)로 친구가 들어옴 → 둘 다 **준비!** 를 누르면 서버가 4.5초 뒤 시작 시각을 정해 **같은 시각에 시작**. 치는 동안 2초마다 서로 점수를 주고받아 위쪽 막대에 표시. 결과 화면에 승패(개인전) / 팀 점수 합계(팀전) + **한 판 더**.
  - 웹소켓 없이 **폴링**(대기실 1.5초 · 치는 중 2초, 화면 안 보이면 쉼). 방 하나 = DB `rooms` 행 하나(JSON), 2시간 안 쓰면 지움. 동시에 고쳐도 안 섞이게 한 문장 UPDATE.
  - 방장이 곡·모드를 고름. 4단계부터는 혼자 칠 때처럼 팔로워 인증한 사람만 준비 가능. 방 판은 **랭킹에 안 올라감**.
  - **팀전**: 지금은 둘 다 드럼으로 점수 합산. 파트 선택(🥁 드럼 / 🎹 피아노)이 준비돼 있어서 피아노가 생기면 `ROOM_PARTS_READY` 에 'piano' 만 넣으면 됨.
- **💬 건의하기**: 곡 추천 / 아이디어 / 버그 / 기타 + 500자. 같은 브라우저 1시간 5개까지. `/admin.html` → **건의함** 탭(처리함·삭제). 봇은 `GET /api/bot/suggestions?days=1&token=…` (환경변수 `SUGGEST_BOT_TOKEN`, 읽기 전용)로 매일 아침 새 건의를 정리.
- **📢 업데이트 소식**: `public/js/news.js` 맨 위에 한 덩어리 추가하면 시작 화면 버튼에 빨간 점 → 누르면 새 글에 NEW. 새 기능 배포할 때마다 같이 고치기.
- **❤️ 광고 이어하기 = 하트 2개** (`REVIVE_LIVES`).
- **💥 연타 구간** (드럼 롤, `level.rolls`): 반짝이는 띠가 내려오면 그 줄을 마구 두드림. 점수·정확도와 상관없음(랭킹 공정), 8번마다 하트 +1(한 구간 최대 2개). 기존 곡은 노트 수를 안 바꾸려고 16단계에만 (새 곡부터 넣기).

### 목숨 · 이어하기 (광고)

- 목숨 **5개** (화면 위 하트). **MISS 할 때마다 1개** 줄어듦. 동시치기 두 개를 다 놓쳐도 1개만. **헛침(노트 없는 곳을 누름)도 1개** 줄어듦 (두 엄지가 동시에 미끄러지면 1개만).
- **콤보 20개마다 목숨 +1** (최대 5개).
- 0개가 되면 그 자리에서 노래가 멈추고 **"광고 보고 이어하기"** 창. 광고를 끝까지 보면 **목숨(하트) 2개로** **그 자리부터** 이어서 침 (`REVIVE_LIVES`) (3초 카운트다운, 이어한 직후 1.6초는 목숨 안 깎임). **한 판에 한 번.**
- 이어하기 안 하면 "실패" 결과(F, 별 0개) — 최고 기록·랭킹·도전장에는 안 들어감.
- 영상 찍기(자동 연주/직접 연주)에는 목숨이 없음.
- 광고: `public/js/config.js` 의 `ads.adsenseClient` 에 애드센스 게시자 ID(`ca-pub-…`)를 넣으면 **구글 애드센스 H5 게임 보상형 광고**가 나옴. 비어 있거나 광고가 없으면(승인 전·광고 재고 없음·광고 차단) 대신 **홍보 화면을 5초** 보여주고 이어하기 (`ads.js`). 홍보 화면 문구는 "팔로우하고 집 한 채 받아가요!" + **@goyangi.seom** 팔로우 버튼 (`config.js` 의 `ads.houseHandle`, 문구는 `index.html` `#modal-ad`).
  - 애드센스 켤 때: ① 애드센스 가입·사이트 승인 ② H5 게임 광고(Ad Placement API) 신청 ③ `public/ads.txt` 에 `google.com, pub-…, DIRECT, f08c47fec0942fa0` 추가 ④ `adsenseClient` 채우기. 승인 전 화면 확인은 `ads.test: true`.

**잠금 정리** (2026-11-17): **1~3단계는 누구나**(맛보기). **4단계부터 15단계와 💎 무제한 모드(그리그·단계별)는 전부 팔로워 인증 완료**(암호 또는 운영자 확인)한 사람만(`charts.js`의 `FREE_UPTO`·`isClosed`, 서버 `/api/runs` 403 `confirm_required`/`confirm_pending`). 건너뛰는 단계 없이 1→15 차례로 열려요. **랭킹도 인증 완료한 사람만** 올라가고 보여요(`/api/scores` 403 `verify_required`, 저장소 랭킹 쿼리가 `checked_at` 있는 사람만). 운영자는 따로 확인할 필요 없음: `/admin.html` → 랭킹 참여자 / 미인증 탭에서 필요하면 삭제만.

**진행 잠금**: 앞 단계를 **별 1개 이상**으로 깨야 다음 단계가 열려요 (`charts.js`의 `isUnlocked`). 잠긴 9단계는 건너뛰어서 8단계를 깨면 10단계가 열리고, 그리그 무제한은 12단계를 깨면 열려요. 오늘의 노래에도 잠긴 단계는 안 나와요. 시작 화면 "바로 시작"은 아직 안 깬 첫 단계. 단, **오늘의 노래**와 **친구 도전장**은 앞 단계를 안 깼어도 칠 수 있음기록은 브라우저(localStorage)에 저장.

### 💎 무제한 모드

- 13단계(터키 행진곡)를 깨면 열림. 한 판 안에서 **Lv.1 → Lv.2 → …** 4마디마다 단계가 오르고 **BPM +10** (90, 100, 110, 120 … 한도 없음).
- 패턴도 같이 어려워짐: Lv.1 기본 쿵짝 → Lv.2 8비트 록 → Lv.3 엇박 → Lv.4 필인 지옥(손가락 꼬임 주의!) → 더블 킥 → 16비트 → 이후 섞어서. 140 BPM 넘으면 16분음표는 빼서 '빠르기'로 승부. 같은 엄지 16분음표 연타는 절대 없음(테스트로 확인).
- 새 단계는 위쪽 HUD 에 "Lv.3 · 엇박 들어갑니다 · 110 BPM" 으로 표시 (가운데 큰 배너는 노트를 가려서 영상 찍기 화면에서만). 빠른 단계일수록 점수 배율 ↑ (단계마다 +10%).
- 목숨 5개 · 광고 이어하기 1번(하트 2개로)은 일반 단계와 같음. 목숨이 다 떨어지면 끝 → **별 대신 다이아몬드 3개**: 💎 Lv.4 클리어 · 💎💎 Lv.7 클리어 · 💎💎💎 Lv.10 클리어 (`DIAMOND_RULES`).
- 반주는 산왕의 궁전에서 — 원곡도 점점 빨라지는 곡. 단계가 오를수록 오케스트라가 커짐.
- 무제한 모드는 **13단계(터키 행진곡)**를 깨면 열림 (`ENDLESS_FROM`). 8단계에 신곡이 끼면서 번호만 12→13 으로 밀렸을 뿐 같은 곡.

### 💎 단계별 무제한

- 단계 고르기 화면 위 **🎵 단계 / 💎 무제한** 탭. 무제한 탭에선 1~15단계마다 그 곡 무제한이 있음 (id `e1`~`e15`).
- 그 단계를 별 1개 이상으로 깨면 열림. 원래 채보를 4마디씩 끝없이 되풀이하고, 4마디마다 **BPM +6** (`LEVEL_ENDLESS_STEP`), 원래 빠르기부터 시작.
- 다이아 기준·목숨·이어하기는 그리그 무제한과 같음. **곡마다 따로 랭킹** (랭킹 창 위 🎵 단계 / 💎 무제한 전환 → 그리그 · 1단계 ∞ … 15단계 ∞). 저장소 level 칸은 그리그 0, 단계별 -1~-15.

9단계부터 악기가 하나씩 늘어요. 화면은 왼쪽부터 **크래시 · 킥 | 스네어 · 하이햇**. 왼쪽 엄지가 크래시·킥, 오른쪽 엄지가 스네어·하이햇을 맡고, 같은 엄지 악기끼리는 동시에 나오지 않습니다. 터치 구역은 화면을 레인 수만큼 세로로 나눈 칸입니다. 하이햇·크래시를 내가 치는 단계에선 반주의 하이햇·크래시가 쉬어요.

랭킹은 **닉네임 + 인스타 아이디**로 참여해요. 한 번 정하면, 끝까지 친 판의 점수가 결과 화면에서 **자동으로** 올라갑니다(등록 버튼 없음).
- 위에서 **🎵 단계 / 💎 무제한** 전환. 단계: **🏆 총 등수**(단계별 최고점 합계, 1·2·3등 시상대) · 1~15단계. 무제한: 그리그 · 1~15단계 ∞ (깬 단계 Lv. 가 높은 순, 같으면 점수).
- **@ok_aystra 를 팔로우해야 랭킹에 들어갈 수 있어요.** 진짜 팔로우 확인은 자동으로 못 해서(인스타 API 한계) 운영자가 `/admin.html` → **랭킹 참여자** 탭에서 인스타 아이디를 눌러 직접 확인하고, 안 했으면 **랭킹에서 내리기** → 바로 랭킹에서 안 보이고, 그 사람이 다시 들어오면 "팔로우 확인이 안 됐어요" 창이 떠서 아이디를 다시 적을 수 있음(적으면 돌아옴). **5일** 안에 안 적으면 자동 삭제(`HIDE_KEEP_MS`). **삭제**는 즉시. 인스타 아이디는 랭킹에 안 보이고 운영자 화면에만 보여요.
- 무제한 모드 점수는 저장소의 `level 0` 칸에 `깬 단계 × 1,000,000 + 점수` 한 숫자로 저장돼요(총 등수에는 안 들어감).

- 쓰는 곡은 전부 **퍼블릭 도메인**: 작곡가 사후 70년이 지난 곡(클래식, 포스터·조플린·피어폰트 같은 옛 노래) 또는 작곡가 미상 전통 민요(작은 별, 성자들의 행진, 코로부시카). 멜로디·코드를 직접 옮겨 적고 Web Audio 로 합성하므로 남의 녹음·편곡을 쓰지 않습니다.

### 판정 · 별

- 노트 없는 곳을 누르면 **헛침**: 점수 없음 + 콤보 끊김 + 정확도 하락 + 목숨 -1

### 쓸만한 주소 옵션

`?gate`·`?debug` 는 **내 컴퓨터(localhost)에서만** 동작합니다. 실제 사이트에서는 무시돼서 잠금을 풀 수 없어요.

| 주소 | 용도 |
|---|---|
| `/?gate=soft` | 12단계·그리그 무제한 인증 잠금 + 9·13·14단계 잠금 미리보기 |
| `/?gate=open` | 잠금 없이 전부 열기 (localhost 전용) |
| `/?level=3` | "바로 시작" 버튼이 3단계로 (릴스 링크에 써도 됨) |
| `/?screen=levels` | 레벨 목록부터 열기 |

## 만드는 순서 (지금 어디까지 왔나)

1. ✅ **게임만** — 1~15단계, 쿵/짝 레인, 콤보, 점수, 등급, 결과 카드 공유

## 배포

**https://kongkong-drum.vercel.app** — Vercel. 이 브랜치(`claude/eloquent-hamilton-5w1xwr`)에 push 하면 자동 배포.

- 사이트 = `public/` (정적), 서버 = **Vercel 함수** `api/server.js` (`vercel.json` 의 rewrites 가 `/api/*` 를 여기로), DB = **Neon Postgres**.
- 서버 코드는 `server/handler.js` 하나를 Node(`npm start`)와 Vercel 함수가 같이 씀. 저장소만 다름: Node = JSON 파일(`server/store.js`), Vercel = Postgres(`server/pgstore.js`). 테이블은 처음 요청 때 자동 생성.
- 함수 지역은 싱가포르(`sin1`). Neon DB 도 **싱가포르(AWS ap-southeast-1)** 로 만들어야 빨라요.
- **Neon 연결 전**에는 `/api/health` 가 503 → 사이트는 서버 없는 모드(랭킹 '곧 오픈')로 그대로 돌아감.
- 기본 설정은 `api/server.js` 의 `DEFAULTS` (12단계·무제한 모드는 팔로워 인증). Vercel 환경변수로 같은 이름을 넣으면 그 값이 우선.
- 비밀값: `ADMIN_TOKEN` (관리자 페이지 비밀번호, Sensitive). `SESSION_SECRET` 은 DB 에 자동 생성.
- `FOLLOW_PASSWORD`: **팔로워 암호** 처음 값 (Sensitive). `/admin.html` → 인증 신청자 탭의 🔑 팔로워 암호에서 바꾸면 DB 값이 우선(빈 값으로 저장하면 환경변수 값으로 돌아감).
- 테스트: `npm test` 가 JSON 저장소와 Postgres 저장소(메모리 Postgres PGlite) 둘 다 같은 흐름으로 시험.

## 실기기 테스트 체크리스트 (중요)

인스타 앱 안 브라우저는 소리·터치가 불안정할 수 있어서 **실제 폰으로** 꼭 확인하세요.

- [ ] 아이폰 인스타 앱 → 링크 열기 → 첫 터치 후 소리 나는지 (무음 스위치 켠 상태도)
- [ ] 안드로이드 인스타 앱 → 같은 확인
- [ ] 두 엄지 동시 터치가 둘 다 잡히는지 (5단계)
- [ ] 영상 찍기 → 파일 저장이 아이폰/안드로이드에서 되는지
- [ ] 판정이 계속 늦거나 빠르면 ⚙ 설정 → "박자 맞춰서 자동 보정"
- [ ] 블루투스 이어폰이면 지연이 커서 보정값이 크게 나올 수 있음
- [ ] 끝까지 치면 닉네임 입력 → 결과 화면에서 알아서 랭킹에 올라가는지
- [ ] 결과 공유: 이미지 길게 눌러 저장 → 스토리 업로드

화면 안내: 인스타 앱 안에서 열면 "외부 브라우저로 열기" 안내가 자동으로 뜹니다.
