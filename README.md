# 🥁 콩콩 드럼

엄지 두 개로 하는 리듬게임. 릴스에서 보고 들어온 사람이 **설치·가입 없이 바로** 해볼 수 있게 만든 웹게임입니다.

- 콘셉트: **공연 무대 위 드럼 세트**. 마스코트 쿵콩이가 드러머로 앉아 있고, 밴드(베이스·건반·하이햇)가 반주를 깔면 **내가 킥과 스네어를 채워 넣는** 구조.
- 노트는 드럼 게임 관례를 따름: **킥 = 레인을 가로지르는 가로 막대**(Rock Band 방식), **스네어 = 둥근 드럼 헤드 패드**.
- 타격감: 킥은 화면 전체가 '쿵' 눌리고 베이스드럼이 부풀며 울림 링, 스네어는 스틱이 내려치고 불꽃·짧은 흔들림. 25콤보마다 크래시 심벌 + 관객 환호, 30콤보부터 GROOVE(조명 빨라짐).
- 카운트인은 드러머처럼 스틱을 머리 위에서 딱딱 치며 "1, 2, 3, 4!"
- 소리는 Web Audio 합성(킥: 서브+펀치+비터 클릭 / 스네어: 통 울림+스냅+스네어 줄 / 작은 방 리버브). 내가 누를 때만 킥·스네어 소리가 납니다.

| 단계 | 이름 | BPM | 잠금 |
|---|---|---|---|
| 1 | 첫 비트 | 84 | 누구나 |
| 2 | 8비트 그루브 | 92 | 누구나 |
| 3 | 엇박 펑크 | 98 | 누구나 |
| **4** | **더블 킥** (왼손 연타, 릴스 메인) | 100 | 팔로우 인증 |
| 5 | 펀치 비트 (킥+스네어 동시) | 108 | 팔로우 인증 |
| 6 | 드럼 솔로 | 120 | 팔로우 인증 |

랭킹 등록도 팔로우 인증이 필요합니다. 인스타 아이디로 올라갑니다.

## 바로 실행

Node.js 20.12 이상. 설치할 패키지는 없습니다.

```bash
cp .env.example .env      # 필요한 값 채우기 (처음엔 비워둬도 돌아감)
npm start                 # http://localhost:3000
npm test                  # 테스트
```

서버 없이 `public/` 폴더만 정적 호스팅해도 게임이 돌아갑니다(GitHub Pages 등). 이때 인증·랭킹은 **브라우저 안 가짜 API**로 동작해서 흐름만 볼 수 있어요.

### 쓸만한 주소 옵션

| 주소 | 용도 |
|---|---|
| `/?gate=follow` | 잠금 흐름 미리보기 (서버 설정이 open이어도) |
| `/?level=4` | "바로 시작" 버튼이 4단계로 |
| `/?screen=levels` | 레벨 목록부터 열기 |

### 🎬 영상 찍기 탭 (릴스 촬영용)

시작 화면 → **영상 찍기**. 단계 · 자동 연주/직접 연주 · 위/아래 문구를 고르고 "녹화 시작".

- 화면이 **9:16** 으로 바뀌고 버튼·점수판이 사라짐 (문구와 점수는 화면 안에 그려짐)
- **영상 파일로 바로 저장** 을 켜면 소리까지 mp4(또는 webm)로 저장 → 공유/다운로드
- 끄면 폰 화면 녹화를 켜고 찍으면 됨 (3초 카운트다운 후 시작)
- 자동 연주는 이 탭에서만 됩니다. 일반 플레이는 항상 직접 눌러야 소리가 나요.

PC에서는 `F`/`D`/`←` = 쿵, `J`/`K`/`→` = 짝, `Space` = 동시, `Esc` = 일시정지.

## 만드는 순서 (지금 어디까지 왔나)

1. ✅ **게임만** — 1~6단계, 쿵/짝 두 레인, 콤보, 점수, 등급, 결과 카드 공유
2. ✅ **서버 인터페이스** — `checkFollow(igsid)`는 지금 **항상 "확인됨"** 을 돌려주는 가짜(`FOLLOW_CHECK_MODE=fake`). 게임은 모두 이 함수를 거칩니다.
3. ⏳ **릴스 올리고 반응 보기** — `GATE_MODE=open`(기본)이면 4단계도 그냥 열려 있어요. 재밌는지부터 확인.
4. ⏳ **진짜 팔로우 확인** — 앱 심사/테스트 결과에 따라 `.env`에서 두 줄만 바꾸면 됩니다:
   ```
   GATE_MODE=follow
   FOLLOW_CHECK_MODE=real
   ```
   자세한 Meta 설정은 [docs/instagram-setup.md](docs/instagram-setup.md).

## 팔로우 인증 흐름

```
[사이트] 4단계 도전 / 랭킹 등록 누름
   → 일회용 코드 표시 (예: 콩콩-K7P2, 10분 유효)
   → "코드 복사하고 DM 열기" (ig.me 링크)
[인스타] 유저가 코드를 DM으로 보냄
   → Meta 웹훅 → POST /webhook
   → 서버가 코드를 찾고 checkFollow(보낸사람 IGSID)
        팔로우 중  → 코드 verified + DM "확인 완료!"
        아님       → DM "팔로우하고 다시 보내줘" (같은 코드 재전송 가능)
[사이트] 2초마다 코드 상태 확인 → verified 면 서명 쿠키(180일) 발급 → 4단계 열림
```

- 코드는 **발급받은 브라우저에서만** 조회됩니다(남이 코드를 보고 가로챌 수 없음).
- 한 번 인증하면 쿠키로 기억. 폰을 바꾸면 다시 인증하면 됩니다.
- DM 앱으로 갔다가 돌아오면서 페이지가 새로 열려도, 대기 중인 코드를 기억해서 이어서 확인합니다.
- 서버 저장 데이터는 딱 두 가지: `codes`(코드, 상태) · `players`(인스타 아이디, 레벨별 최고 점수, 팔로우 확인 시각).

## 점수 위조 방지 (최소한)

- 판 시작 때 서버가 서명한 토큰을 주고, 등록 때 확인
- 곡 길이보다 빨리 제출하면 거부, 같은 판 토큰은 한 번만
- 판정 개수 합 = 노트 수, 점수는 판정 개수로 가능한 범위 안이어야 함

랭킹 1위를 릴스 소재로 쓰기 전에는 상위 기록을 한 번 눈으로 확인하는 걸 추천합니다.

### 레벨 추가/수정

`public/js/charts.js`의 `LEVELS`에 객체 하나 추가하면 끝. 한 마디 = 16칸:

```js
bars: [
  'K...S...K...S...',   // K=쿵  S=짝  B=동시  .=쉼
  'KKKKS...KKKKS...',
]
```

반주(`song`)는 `root`(조), `prog`(코드 진행), `hat`/`bass`/`chord`/`lead` 16칸 패턴으로 정합니다. 멜로디는 레벨마다 고정 시드로 자동 생성돼서 매번 같은 곡이 나와요.

## 배포

**지금 배포된 곳: https://kongkong-drum.vercel.app** (Vercel, 정적. GitHub 이 브랜치에 push 하면 자동 재배포)

- 지금은 서버 없이 게임만 올라가 있어요. 랭킹은 "곧 오픈"으로 표시되고, 4단계도 열려 있습니다(지금은 1~3단계 진행 중).
- 4단계에서는 `/api`를 Vercel Functions로 옮기고 저장소를 Supabase/Neon 같은 DB로 바꿉니다(Vercel은 파일 저장이 안 됨).

- **서버 포함(추천)**: Render / Railway / Fly.io 같은 Node 호스팅. `data/` 폴더가 유지되는 디스크(볼륨)를 붙이세요. 환경변수: `NODE_ENV=production`, `SESSION_SECRET`, `INSTAGRAM_HANDLE`, `SITE_URL`, `ALLOW_DEV_SIMULATE=false`.
- **정적만**: `public/`을 GitHub Pages / Netlify / Vercel에 올리면 게임은 바로 됩니다(인증·랭킹은 가짜).
- 트래픽이 커지면 `server/store.js`를 같은 메서드 모양으로 Postgres(Supabase 등) 버전으로 바꾸면 됩니다.

## 실기기 테스트 체크리스트 (중요)

인스타 앱 안 브라우저는 소리·터치가 불안정할 수 있어서 **실제 폰으로** 꼭 확인하세요.

- [ ] 아이폰 인스타 앱 → 링크 열기 → 첫 터치 후 소리 나는지 (무음 스위치 켠 상태도)
- [ ] 안드로이드 인스타 앱 → 같은 확인
- [ ] 두 엄지 동시 터치가 둘 다 잡히는지 (5단계)
- [ ] 영상 찍기 → 파일 저장이 아이폰/안드로이드에서 되는지
- [ ] 판정이 계속 늦거나 빠르면 ⚙ 설정 → "박자 맞춰서 자동 보정"
- [ ] 블루투스 이어폰이면 지연이 커서 보정값이 크게 나올 수 있음
- [ ] DM 열기 → 코드 보내기 → 다시 돌아왔을 때 자동으로 열리는지
- [ ] 결과 공유: 이미지 길게 눌러 저장 → 스토리 업로드

화면 안내: 인스타 앱 안에서 열면 "외부 브라우저로 열기" 안내가 자동으로 뜹니다.
