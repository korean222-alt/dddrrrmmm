# 🥁 콩콩 드럼

엄지 두 개로 하는 리듬게임. 릴스에서 보고 들어온 사람이 **설치·가입 없이 바로** 해볼 수 있게 만든 웹게임입니다.

- 콘셉트: **공연 무대 위 드럼 세트**. 마스코트 쿵콩이가 드러머로 앉아 있고, 밴드가 **누구나 아는 클래식 명곡**(환희의 송가, 캉캉, 터키 행진곡…)을 연주하면 **내가 킥과 스네어를 채워 넣는** 구조.
- 노트는 드럼 게임 관례를 따름: **킥 = 레인을 가로지르는 가로 막대**(Rock Band 방식), **스네어 = 둥근 드럼 헤드 패드**.
- 타격감: 킥은 화면 전체가 '쿵' 눌리고 베이스드럼이 부풀며 울림 링, 스네어는 스틱이 내려치고 불꽃·짧은 흔들림. 25콤보마다 크래시 심벌 + 관객 환호, 30콤보부터 GROOVE(조명 빨라짐).
- 카운트인은 드러머처럼 스틱을 머리 위에서 딱딱 치며 "1, 2, 3, 4!"
- 화면은 **피아노 타일처럼 세로 줄**: 줄 맨 아래에 그 줄의 악기(크래시·킥·스네어·하이햇)가 놓여 있고, **줄 아무 데나 누르면** 그 악기가 울림. 카운트인 때 줄마다 "왼쪽 엄지 / 킥 (쿵)" 말풍선과 물결 표시.
- 곡(멜로디·화음·베이스)은 **진짜 그랜드 피아노 샘플**로 연주(`public/audio/piano/`, 21개 · 약 420KB). 샘플을 못 받으면 예전 합성음으로 대신 연주.
- 드럼 소리는 Web Audio 합성(킥: 서브+펀치+비터 클릭 / 스네어: 통 울림+스냅+스네어 줄 / 작은 방 리버브). 내가 누를 때만 킥·스네어 소리가 납니다.
- 결과 화면에서 별이 하나씩 뜰 때 '띵!' 효과음, 별 3개면 짜잔 화음. 박자가 한쪽으로 계속 밀리면(블루투스 이어폰 등) "내 손에 맞게 자동 보정" 버튼이 나옴.

### 오늘의 노래 · 1:1 대결

- 시작 화면 **오늘의 노래**: 한국 시간 자정마다 바뀌는 곡 (`versus.js`의 `TODAY_ORDER`, 이틀 연속 같은 곡 없음).
- 결과 화면 **친구에게 1:1 도전장**: 내 점수 + 마디별 점수 기록을 링크(`?vs=…`)에 담아 카톡·DM으로 보냄. 받은 사람이 같은 곡을 치면 화면 위에 **상대 점수가 실시간으로 같이 올라가는 막대**가 나오고, 끝나면 승리/패배 + "다시 도전장 보내기".
- 서버 없이 되는 방식이라 링크 값은 고칠 수 있음 → 랭킹 같은 공식 기록으로는 안 씀. 동시에 접속해서 치는 실시간 대결은 서버(웹소켓)가 있어야 함.

| 단계 | 곡 | 드럼 기술 | 난이도 | BPM | 잠금 |
|---|---|---|---|---|---|
| 1 | 환희의 송가 (베토벤) | 킥·스네어 기본기 | ●○○○○ 입문 | 84 | 누구나 |
| 2 | 캐논 (파헬벨) | 8비트 그루브 | ●●○○○ 쉬움 | 92 | 누구나 |
| 3 | 아이네 클라이네 (모차르트) | 엇박 | ●●●○○ 보통 | 98 | 누구나 |
| 4 | 산왕의 궁전에서 (그리그) | 더블 킥 | ●●●●○ 어려움 | 100 | 인스타 팔로우 |
| 5 | 캉캉 (오펜바흐) | **+하이햇** (3레인) | ●●●●○ 어려움 | 108 | 인스타 팔로우 |
| 6 | 터키 행진곡 (모차르트) | **+크래시** (4레인) | ●●●●● 지옥 | 112 | 인스타 팔로우 |

5단계부터 악기가 하나씩 늘어요. 화면은 왼쪽부터 **크래시 · 킥 | 스네어 · 하이햇**. 왼쪽 엄지가 크래시·킥, 오른쪽 엄지가 스네어·하이햇을 맡고, 같은 엄지 악기끼리는 동시에 나오지 않습니다. 터치 구역은 화면을 레인 수만큼 세로로 나눈 칸입니다. 하이햇·크래시를 내가 치는 단계에선 반주의 하이햇·크래시가 쉬어요.

랭킹 등록은 DM 팔로우 인증이 필요합니다. 인스타 아이디로 올라갑니다.

### 곡 저작권

- 피아노 소리: [Salamander Grand Piano V3](https://archive.org/details/SalamanderGrandPianoV3) by Alexander Holm, **CC BY 3.0** (출처 표시 필요 — 설정 화면 아래에 표시). 3초로 자르고 모노 56kbps로 줄여서 씀.
- 실제 연주 녹음 파일을 안 쓰는 이유: 곡은 퍼블릭 도메인이어도 **녹음(연주)에는 따로 저작인접권**이 있고, 사람이 연주한 녹음은 빠르기가 계속 흔들려서 드럼 노트를 정확히 맞추기 어려움. 그래서 악보대로 정박에 피아노 샘플을 직접 연주.

- 쓰는 곡은 전부 **작곡가 사후 70년이 지난 클래식(퍼블릭 도메인)**. 멜로디·코드를 직접 옮겨 적고 Web Audio 로 합성하므로 남의 녹음·편곡을 쓰지 않습니다.
- 최신 가요·팝은 **멜로디만 다시 연주해도 작곡 저작권**이 걸립니다(음원 파일이 아니어도). 피아노타일 같은 게임은 음악 출판사/음반사와 정식 라이선스 계약을 맺고 씁니다.
- 곡을 추가할 때도 같은 기준: 작곡가 사망 후 70년 지난 곡 + 직접 만든 편곡. (예: 학교종·산토끼 같은 동요는 작곡가가 최근에 돌아가셔서 아직 저작권이 있어요.)

### 판정 · 별

- 노트 없는 곳을 누르면 **헛침**: 점수 없음 + 콤보 끊김 + 정확도 하락
- 노트보다 0.15~0.26초 너무 일찍 누르면 그 노트는 **MISS** → 마구 연타하면 점수가 거의 0
- 별 3개 = 미스·헛침 없이 정확도 90% 이상 / 2개 = 75% 이상 / 1개 = 50% 이상 (기준은 `charts.js`의 `STAR_RULES`)

## 바로 실행

Node.js 20.12 이상. 설치할 패키지는 없습니다.

```bash
cp .env.example .env      # 필요한 값 채우기 (처음엔 비워둬도 돌아감)
npm start                 # http://localhost:3000
npm test                  # 테스트
```

서버 없이 `public/` 폴더만 정적 호스팅해도 게임이 돌아갑니다(GitHub Pages 등). 이때 인증·랭킹은 **브라우저 안 가짜 API**로 동작해서 흐름만 볼 수 있어요.

### 쓸만한 주소 옵션

| 주소 | 용도 |
|---|---|
| `/?gate=follow` | DM 인증 잠금 흐름 미리보기 |
| `/?gate=open` | 잠금 없이 전부 열기 (테스트용) |
| `/?gatefrom=1` | 1단계부터 팔로우 잠금 미리보기 |
| `/?level=4` | "바로 시작" 버튼이 4단계로 |
| `/?screen=levels` | 레벨 목록부터 열기 |

### 🎬 영상 찍기 탭 (릴스 촬영용)

시작 화면 → **영상 찍기**. 단계 · 자동 연주/직접 연주 · 위/아래 문구를 고르고 "녹화 시작".

- 화면이 **9:16** 으로 바뀌고 버튼·점수판이 사라짐 (문구와 점수는 화면 안에 그려짐)
- **영상 파일로 바로 저장** 을 켜면 소리까지 mp4(또는 webm)로 저장 → 공유/다운로드
- 끄면 폰 화면 녹화를 켜고 찍으면 됨 (3초 카운트다운 후 시작)
- 자동 연주는 이 탭에서만 됩니다. 일반 플레이는 항상 직접 눌러야 소리가 나요.

PC에서는 `F`/`←` = 킥, `J`/`→` = 스네어, `Space` = 동시, `Esc` = 일시정지. 3레인은 `F` `J` `K`, 4레인은 `D` `F` `J` `K` (왼쪽부터).

## 만드는 순서 (지금 어디까지 왔나)

1. ✅ **게임만** — 1~6단계, 쿵/짝 두 레인, 콤보, 점수, 등급, 결과 카드 공유
2. ✅ **서버 인터페이스** — `checkFollow(igsid)`는 지금 **항상 "확인됨"** 을 돌려주는 가짜(`FOLLOW_CHECK_MODE=fake`). 게임은 모두 이 함수를 거칩니다.
3. ⏳ **릴스 올리고 반응 보기** — 지금 기본값은 `soft`: 4단계를 누르면 "인스타 팔로우하고 오세요" 안내 → 팔로우 버튼 누르고 돌아오면 열림(진짜 확인은 아님). 처음부터 팔로우를 받으려면 `gateFromLevel: 1`(서버는 `GATE_FROM_LEVEL=1`).
4. ⏳ **진짜 팔로우 확인** — 앱 심사/테스트 결과에 따라 `.env`에서 두 줄만 바꾸면 됩니다:
   ```
   GATE_MODE=follow
   FOLLOW_CHECK_MODE=real
   ```
   자세한 Meta 설정은 [docs/instagram-setup.md](docs/instagram-setup.md).

## 팔로우 인증 흐름

```
[사이트] 4단계 도전 / 랭킹 등록 누름
   → 일회용 코드 표시 (예: 콩콩-K7P2, 10분 유효)
   → "코드 복사하고 DM 열기" (ig.me 링크)
[인스타] 유저가 코드를 DM으로 보냄
   → Meta 웹훅 → POST /webhook
   → 서버가 코드를 찾고 checkFollow(보낸사람 IGSID)
        팔로우 중  → 코드 verified + DM "확인 완료!"
        아님       → DM "팔로우하고 다시 보내줘" (같은 코드 재전송 가능)
[사이트] 2초마다 코드 상태 확인 → verified 면 서명 쿠키(180일) 발급 → 4단계 열림
```

- 코드는 **발급받은 브라우저에서만** 조회됩니다(남이 코드를 보고 가로챌 수 없음).
- 한 번 인증하면 쿠키로 기억. 폰을 바꾸면 다시 인증하면 됩니다.
- DM 앱으로 갔다가 돌아오면서 페이지가 새로 열려도, 대기 중인 코드를 기억해서 이어서 확인합니다.
- 서버 저장 데이터는 딱 두 가지: `codes`(코드, 상태) · `players`(인스타 아이디, 레벨별 최고 점수, 팔로우 확인 시각).

## 점수 위조 방지 (최소한)

- 판 시작 때 서버가 서명한 토큰을 주고, 등록 때 확인
- 곡 길이보다 빨리 제출하면 거부, 같은 판 토큰은 한 번만
- 판정 개수 합 = 노트 수, 점수는 판정 개수로 가능한 범위 안이어야 함

랭킹 1위를 릴스 소재로 쓰기 전에는 상위 기록을 한 번 눈으로 확인하는 걸 추천합니다.

### 레벨 추가/수정

`public/js/charts.js`의 `LEVELS`에 객체 하나 추가하면 끝. 드럼 채보는 한 마디 = 16칸:

```js
bars: [
  'K...S...K...S...',   // K=킥  S=스네어  H=하이햇  C=크래시  .=쉼
  'KKKKS...J.H.X...',   // 동시: B=킥+스네어  J=킥+하이햇  X=크래시+스네어
]
```

반주(`song`):

```js
song: {
  melody: ['E5 E5 F5 G5', 'E5:6 D5:2 D5:8'],  // 음이름:길이(16분음표 칸, 생략=4). '_' = 쉼. 마디마다 합 16
  prog: ['C', 'G C'],                          // 마디별 코드. 두 개면 반 마디씩 (Am, F#m, G7 …)
  hat: 'x...x...x...x...', bass: 'x.......x.......', chord: 'x.......x.......',
}
```

멜로디·코드가 채보보다 짧으면 반복됩니다. `npm test`가 마디 길이(16칸)를 검사해 줘요.

## 배포

**지금 배포된 곳: https://kongkong-drum.vercel.app** (Vercel, 정적. GitHub 이 브랜치에 push 하면 자동 재배포)

- 지금은 서버 없이 게임만 올라가 있어요. 랭킹은 "곧 오픈"으로 표시되고, 4단계도 열려 있습니다(지금은 1~3단계 진행 중).
- 4단계에서는 `/api`를 Vercel Functions로 옮기고 저장소를 Supabase/Neon 같은 DB로 바꿉니다(Vercel은 파일 저장이 안 됨).

- **서버 포함(추천)**: Render / Railway / Fly.io 같은 Node 호스팅. `data/` 폴더가 유지되는 디스크(볼륨)를 붙이세요. 환경변수: `NODE_ENV=production`, `SESSION_SECRET`, `INSTAGRAM_HANDLE`, `SITE_URL`, `ALLOW_DEV_SIMULATE=false`.
- **정적만**: `public/`을 GitHub Pages / Netlify / Vercel에 올리면 게임은 바로 됩니다(인증·랭킹은 가짜).
- 트래픽이 커지면 `server/store.js`를 같은 메서드 모양으로 Postgres(Supabase 등) 버전으로 바꾸면 됩니다.

## 실기기 테스트 체크리스트 (중요)

인스타 앱 안 브라우저는 소리·터치가 불안정할 수 있어서 **실제 폰으로** 꼭 확인하세요.

- [ ] 아이폰 인스타 앱 → 링크 열기 → 첫 터치 후 소리 나는지 (무음 스위치 켠 상태도)
- [ ] 안드로이드 인스타 앱 → 같은 확인
- [ ] 두 엄지 동시 터치가 둘 다 잡히는지 (5단계)
- [ ] 영상 찍기 → 파일 저장이 아이폰/안드로이드에서 되는지
- [ ] 판정이 계속 늦거나 빠르면 ⚙ 설정 → "박자 맞춰서 자동 보정"
- [ ] 블루투스 이어폰이면 지연이 커서 보정값이 크게 나올 수 있음
- [ ] DM 열기 → 코드 보내기 → 다시 돌아왔을 때 자동으로 열리는지
- [ ] 결과 공유: 이미지 길게 눌러 저장 → 스토리 업로드

화면 안내: 인스타 앱 안에서 열면 "외부 브라우저로 열기" 안내가 자동으로 뜹니다.
