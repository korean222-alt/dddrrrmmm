# 🎹 피아노 타일 규칙 (2026-11-26 밤, 사용자 요청으로 다시 만듦)

사용자: "디테일은 전부 피아노 타일을 따라 해", "모든 맵에 타일 크기는 전부 같게 하고 바꾸지 않게 md 파일에도 적어".

## ⚠ 바꾸지 말 것
- **보통 타일 크기는 모든 곡·유저 맵에서 똑같다**: 화면 높이 / `TILE_ROWS`(4). 곡마다 타일 높이를 다르게 하지 말 것.
  - 곡마다 다른 건 '한 줄 = 몇 16분 칸'(`u`, 가장 흔한 음 간격, 적어도 8분음표)과 빠르기(초당 줄 `TILE_RPS`)뿐.
  - 긴 타일(꾹)만 길이가 다름: 쉼 없이 두 줄 이상 끄는 음 = `rows` 줄짜리 긴 타일.
- 타일에 금색 줄·금색 무늬 넣지 말 것 (11-26 사용자 '금색 없애').
- 다이아는 숫자(💎×0)로 쓰지 말고 **빈 다이아 3개가 별처럼 차오름**.

## 규칙 (tiles.js · tilegame.js)
- 맨 아래 「시작」 타일을 누르면 내려오기 시작 (대결은 서버가 정한 시각에 같이 3·2·1).
- 다음 칠 타일(가장 아래)이 화면에 보이면 언제 눌러도 됨. 판정 글자 없음. 빠른 음은 바로 위 타일(한 줄 안)도 칠 수 있음.
- 누르면 그 음이 남 (반주가 따로 흐르지 않음, 반 마디 첫 타일엔 왼손 낮은 음 둘). → 화면 시계는 performance.now 만 씀(소리 시계 안 따라감 = 끊김 없음).
- 친 타일 = 옅은 회색, 놓침·빈 칸 누름 = 빨강 + 하트 하나 (하트 3, 바퀴마다 하나 회복). 차례 아닌 검은 타일을 누른 건 벌 없음.
- 긴 타일: 누른 채로 있으면 손가락 자리까지 파랗게 차오름, 끝까지면 +(줄 수 - 1).
- 점수 = 친 타일 + 긴 타일 덤. 서버 `checkTileRun` 은 '그 시간 안에 화면에 들어온 타일 점수'(`tilesWithin`)까지만.
- 한 바퀴 = 곡 하나 처음부터 끝까지. 조각뿐이던 곡은 `TILE_MEL` 에 곡 전체(징글벨 절+후렴 등). 28초(`LAP_MIN_SEC`)보다 짧으면 한 옥타브 바꾼 변주를 뒤에 붙임.
- 첫 바퀴: 별 3개(1/3·2/3·끝) → 둘째 바퀴(빨라짐): 다이아 3개 똑같이 → 그 뒤로도 바퀴마다 +12% 빨라지며 계속 (`MAX_LAPS` 16).
- 이웃 타일 사이는 첫 바퀴에서 0.13초(`MIN_GAP`) 이상 — 넘으면 곡 빠르기를 낮춤.
- 스킨: 상점 콩 스킨 = 타일 색, 무대 = 배경 그림(어둡게), 라이브·시즌 1 세트 = 세트 무대. 기본은 흰 바탕 검은 타일.

## 🎹 유저 맵 타일
- 맵 만들기 맨 위 「🥁 드럼 맵 / 🎹 타일 맵」. 타일 맵은 드럼 탭 없음, 멜로디(건반·노래 파일·악보 파일 다 됨)로 타일.
- 맵 JSON `kind: 'tiles'` (cleanMap 이 남김, 멜로디 음 8개 이상). DB 에 열 안 늘리고 maps.diff 에 +100 → 목록 `kind`.
- 2바퀴(`MAP_TILE_LAPS`)에서 끝, 랭킹 mode `tiles` (점수 ≤ `mapTileMax`). 코인은 친 타일 둘에 1개.
