# 🎭 장거리 곡 만드는 법 (네순 도르마로 해 본 방법, 2026-11-21)

장거리 = 곡 하나를 처음부터 끝까지. 왼쪽 엄지 = 쿵, 오른쪽 엄지 = 멜로디(누르면 두 손 피아노 소리).
새 곡도 이 순서대로 하면 된다.

## 1. 곡 고르기
- **퍼블릭 도메인만**: 작곡가 사후 70년 지난 곡(푸치니 1924년 사망 → OK). 찬송가는 안 됨.
- 녹음(가수·오케스트라 연주)은 저작권이 따로 있으니 **게임에 넣지 않는다.** 멜로디는 악보에서만.

## 2. 악보 구하기 (IMSLP)
- 이 환경 허용 목록에 imslp.org 등이 들어 있었는데 **11-21 오후엔 다시 막힘**(프록시 403) → 곡 페이지도 사용자에게 링크로 받아 달라고 함.
- 곡 페이지(`https://imslp.org/wiki/곡이름_(작곡가)`)는 curl 로 받아짐 → `Special:ImagefromIndex/번호` 중
  **Vocal Score**(피아노+노래) 또는 그 곡만 뽑은 발췌본을 찾는다. 네순 도르마 = **#869125** (1926 리코르디, 6쪽).
- **PDF 파일은 사람 확인(캡차)이 떠서 Claude 가 못 받음 → 사용자에게 링크를 주고 폰으로 받아 캡처해 달라고 한다.** 캡차를 우회하지 말 것.

## 3. 악보 읽기 (멜로디 옮기기)
- 캡처 이미지를 PIL 로 **노래 줄만 잘라 4~5배 확대**(한 줄을 4조각) → 오선 5줄 위치를 기준으로 음 높이를 읽음.
  - 오선(높은음자리표): 위에서부터 F5·D5·B4·G4·E4 줄, 사이 칸 E5·C5·A4·F4. 덧줄 위는 A5(덧줄), B5(그 위 칸).
  - 조표 확인(네순 도르마는 G 조표 + 임시표 C# = 라장조). 테너 악보는 소리가 한 옥타브 아래지만 **피아노 음으로는 악보 표기 그대로** 쓰면 밝고 좋음.
- 리듬은 마디마다 박 합이 맞는지 꼭 셈(4/4 = 16칸).
- 헷갈리는 곳은 앞뒤 같은 선율(같은 주제가 여러 번 나옴)과 비교해서 정함.
- ❌ **녹음에서 음 뽑기는 쓰지 말 것**: Spleeter 로 목소리 분리 + pyin/Basic Pitch 로 해 봤는데 비브라토·오케스트라 때문에 음이 틀려서 사용자가 '원곡이랑 다르다'고 함.

## 4. charts.js 에 넣기
```js
{
  id: 23,               // 비어 있는 번호 (18·20 은 쓰지 말 것)
  long: true,           // 장거리 탭에만, 본편·총 등수·멀티·무제한 밖
  tapMelody: true,      // 오른쪽 줄 = 멜로디, 누르면 피아노 (반주는 멜로디 안 침)
  theme: 'hall',
  name, composer, sub, tagline, difficulty, bpm,
  lanes: [KICK, SNARE],
  song: {
    prog: [...마디별 코드],                // 멜로디 음이 들어 있는 코드로
    hat: '................', bass: '................', chord: '................',
    pianoLH: true,                          // 왼손 피아노(베이스 + 펼친 화음)
    melody: ['_:12 D5:3 D5:1', ...],        // "음:16분칸수", 쉼 = _, 마디 합 16
  },
  kick: [0, 0, 1, ...],  // 마디별 쿵: 0 = 1·3박, 1 = 박마다
  bars: null,            // tapBars() 가 멜로디로 자동 생성
}
```
- 2/4 마디는 16칸에 맞춰 뒤에 반 마디 쉼(`B4:8 _:8`). 셋잇단은 2+1+1칸.
- 소리: `pianoHarmony`(오른손 화음, 긴 음은 둘) · `pianoLeftHand`(왼손 베이스→5도→옥타브→3도).

## 5. 확인용 소리 만들어 사용자에게 듣게 하기
- **반드시 게임 샘플로**: `public/audio/piano.bin`·`orch.bin` 을 풀어서(앞 4바이트 = 헤더 길이, JSON 목차, 그 뒤 mp3들)
  파이썬으로 멜로디(피아노 + 화음) + 왼손 + 현악 패드를 그대로 렌더링 → mp3 (예: `tasks/nessun/full_melody_preview.mp3`).
- ❌ 사인파 합성음은 '기계음'이라 사용자가 싫어함.
- 사용자가 들어 보고 OK 하면 배포.

## 6. 테스트·배포
- `npm run bundle` → `npm test` (core.test.js 의 '🎭 장거리' 테스트가 멜로디 콩 = 악보 음인지 봄).
- news.js 소식 추가 → 기본 브랜치 푸시 → 새 `app.js?v=` 확인.

## 해 봤는데 안 된 것 (다시 하지 말 것)
- ElevenLabs 음악 생성으로 원곡 멜로디 부르게 하기 → 다른 노래를 지어냄. 참고 음원 칸은 오류로 실패.
- TTS 를 멜로디 음높이에 맞추기 → 어색함. ElevenLabs 목소리 바꾸기(STS)는 음높이를 말하는 높이로 끌어내려 멜로디가 망가짐.
- 멜로디 띠를 누르고 미는 게임(longplay.js) → '재미없다'고 해서 지움.
