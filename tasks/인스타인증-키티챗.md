## 지금 동작 (2026-11-17 배포, 운영 중)
### 잠금
- **1~3단계**: 누구나 (맛보기). `charts.js` `FREE_UPTO = 3`.
- **4~15단계 + 💎 무제한(그리그 `endless`, 단계별 `e1`~`e15`)**: 인증 완료한 사람만. `isClosed(id)`, 서버 `/api/runs` 403 `confirm_required`(참여자 없음/아이디만) · `confirm_pending`(아이디만 적고 확인 전).
- 건너뛰는 단계 없음 (`SKIP_LEVELS = []`), 1→15 차례로. 그리그 무제한은 12단계를 깨면.
- `VERIFY_LEVELS`/`needsVerify` 는 예전 '신청만 해도 열림' 단계용 → 이제 비어 있음(호환용으로만 남김).

### 멀티 · 건의하기 (2026-11-18)
- **⚔️ 멀티**(빠른 대결·친구 방 만들기·코드로 들어가기)와 **💬 건의하기**도 인증 완료한 사람만. 화면: 첫 화면 버튼에 🔒, 누르면 인증 창(인증하면 이어서 그 창이 열림, `openVerify(null, { label, then })`). 서버: `/api/rooms` 의 create·join·quick, `/api/suggestions` 403 `confirm_required`/`confirm_pending`. 이미 들어온 방의 sync·leave·again 은 방 열쇠로.

### 랭킹
- 점수 등록(`/api/scores`)은 인증 완료한 사람만 (403 `verify_required`). `GATE_MODE=open` 이면 예외(개발용).
- 랭킹 조회(단계·총 등수·무제한)도 `checked_at` 있는 사람만 (`store.js` / `pgstore.js` 둘 다).
- 랭킹엔 **닉네임**만 보이고 인스타 아이디는 안 보임.

### 인증 = "인증 완료" = `players.checked_at`
- **팔로워 암호**: `POST /api/verify/password { name?, ig?, password }`
  - 처음 온 사람은 닉네임 + 인스타 아이디 필수, 이미 참여한 사람은 암호만.
  - 맞으면 `setChecked(true)` → 바로 전부 열림. 틀리면 아무것도 저장 안 함(403 `wrong_password`).
  - 띄어쓰기·대소문자 무시(`samePassword`). **틀린 시도만** 세서 IP 당 10분에 10번 → 429.
- **관리자 화면** (2026-11-17~): 수동 확인 없음. `/admin.html` → **랭킹 참여자**(인증 완료) / **미인증**(아이디만 적었거나 예전 참가자, 잠김·랭킹 안 보임) 탭, 둘 다 **삭제**만. 미인증 탭엔 '미인증 전부 삭제'. 서버의 확인함·내리기 API(`/api/admin/players/check`, `/hide`)는 남아 있지만 화면에선 안 씀.
- 인스타 아이디를 바꾸면 `checked_at` 이 지워져서 다시 인증해야 함.
- 예전 "아이디만 적고 신청하기" 경로는 화면에서 없앰. `/api/guest` 는 인증한 사람의 닉네임·아이디 바꾸기용으로 남김.

### 팔로워 암호 관리
- 처음 값: Vercel 환경변수 `FOLLOW_PASSWORD` (Sensitive, production). **코드·저장소에 암호를 쓰지 않는다.**
- 교체: `/admin.html` → 인증 신청자 탭 → 🔑 팔로워 암호 (`GET/POST /api/admin/follow-password`). DB `settings`(`set:followPassword`, JSON 저장소는 `settings.followPassword`) 값이 환경변수보다 우선, 빈 값으로 저장하면 환경변수로 돌아감.
- **주 1회 교체**, 바꿀 때 키티챗 DM 문구도 같이 바꾼다.

### 인증 창 (`public/index.html` `#modal-verify`, `main.js` `openVerify`/`submitVerify`)
1. 팔로우하기 → 2. 아무 게시물·릴스에 「쿵」 댓글 → 3. DM 버튼 눌러 팔로워 암호 받기 → 4. 닉네임·아이디·암호 적고 인증하기.
- 잠긴 단계·무제한·랭킹 참여 버튼·1~3단계 끝난 뒤 랭킹 올릴 때 이 창이 뜸.
- DM 링크 `/?k=암호` 로 들어오면 창이 열리고 암호가 미리 채워짐(주소에서는 지움).
- 키워드는 `VERIFY_KEYWORD = '쿵'` — 키티챗 키워드와 같아야 함.
