# 작업: 팔로우 인증으로 기능 열기 (댓글 코드 + 키티챗 팔로워 암호)

새 채팅에서 이 파일과 CLAUDE.md, README.md 를 먼저 읽고 시작한다. (2026-11-16 결정)
고양이섬(korean222-alt/instaer) `tasks/opus-5-인스타인증-키티챗.md` 와 같은 방식이다. 키티챗 Pro 계정 2개 중 하나를 드럼용으로 쓴다.

## 결론 (왜 이 방식인가)
- 사용자는 **사업자 등록을 할 수 없다** → Meta 앱 심사(고급 권한) 불가 → 아무 유저의 DM 을 받는 웹훅은 못 쓴다. (예전 DM 웹훅·코드 인증은 이 이유로 삭제됨)
- 매니챗 Pro 는 웹훅 + 팔로워 조건이 되지만 비싸서 제외. **키티챗 Pro ($22/월, 인스타 계정 2개)** 로 결정.

## 키티챗 상담 확인 내용 (사람 상담원 답변)
- ✅ 계정 2개 연결(Pro) / ✅ 릴스 댓글 자동 DM / ✅ 팔로워 여부에 따라 다른 버튼 DM / ✅ 키워드 포함 댓글에만 발송 / ✅ 모든 게시물 한 번에 적용 / ✅ DM 무제한
- ❌ **외부 주소로 API/웹훅 부르는 기능 없음** → 키티챗은 우리 서버에 "누가 보냈는지" 알려줄 수 없다.
- 동작: 기본 메시지는 댓글 단 모두에게, 버튼을 누를 때 팔로우 상태에 따라 후속 메시지가 달라진다.
- 미확인(가입 후 시험): 팔로우 후 버튼 다시 누르면 팔로워 메시지가 나오는지 / 문구 수정이 전체에 바로 반영되는지 / 여러 번 댓글 달면 DM 이 매번 가는지.

## 역할 나누기
| 확인할 것 | 누가 | 방법 |
|---|---|---|
| 진짜 그 아이디 주인인가 | **우리 서버** | 내 게시물·릴스 댓글을 Meta API 로 읽어 코드와 댓글 쓴 아이디를 맞춘다 |
| 팔로워인가 | **키티챗** | 팔로워에게만 보이는 버튼 DM 에 "팔로워 암호"(주 1회 교체)를 넣는다 |

## 유저 흐름
1. 잠긴 기능(12단계, 그리그 💎 무제한 등)을 누르면 "팔로우 인증" 창 → 코드 `쿵-XXXX` 발급(15분 유효).
2. 지정 릴스/게시물에 코드를 댓글로 → 서버가 댓글을 읽고 아이디 인증.
3. 키티챗이 `쿵-` 키워드 댓글에 버튼 DM → 팔로워면 "팔로워 암호: ○○○"(또는 암호 든 링크 `/?k=암호`).
4. 사이트에 암호 입력(또는 링크) → `players.follow_verified_at` 기록 → 기능 열림. 창은 몇 초마다 상태 확인해서 저절로 바뀐다.

## Vercel 에서 주의할 점 (고양이섬과 다른 부분)
- **Vercel 무료(Hobby) Cron 은 하루 1번만** 돈다 → 5분 주기 불가. 대신 **인증 창이 상태를 물어볼 때 서버가 댓글을 읽는다**(전체에서 30초에 1번만 실제 호출, 마지막 확인 시각은 `settings` 에 저장). 기다리는 사람이 없으면 호출도 없다.
- **예비 확인(창을 닫고 나간 사람용)**: GitHub Actions 예약 실행(`.github/workflows/check-comments.yml`, `*/10 * * * *`)이 10분마다 `POST /api/verify/poll`(비밀값 `CRON_SECRET` 헤더)을 부른다. 무료.
  - GitHub 예약은 몇 분~수십 분 늦거나 건너뛸 수 있다. 마지막 실행 시각을 `settings` 에 기록하고 admin 에 보여서, **자주 늦으면(예: 간격이 30분 넘는 일이 잦으면) cron-job.org(무료, 1분 단위 가능)로 바꾼다.** 같은 주소·같은 비밀값이라 서버 코드는 그대로, 예약 쪽만 갈아끼우면 된다.
  - 서버 이전(Cloudflare 등)은 하지 않는다(CLAUDE.md: Cloudflare 안 씀).
- Meta 토큰은 Vercel 환경변수(`IG_TOKEN`, `IG_USER_ID`)에. 장기 토큰 60일 만료 → 읽을 때마다 남은 기간 보고 자동 갱신, 새 토큰은 `settings` 에 저장.
- 저장소 둘 다(`server/store.js` JSON, `server/pgstore.js` Postgres) 같은 함수로 만들고 `npm test` 둘 다 통과.

## Meta 개발자 앱 (사업자 불필요로 판단, 실제 확인 필요)
- developers.facebook.com = 인스타에 "내 서버가 내 계정 댓글을 읽어도 된다"고 허락(출입증)하는 곳. 폰 앱이 아니라 신청서 이름.
- **개발 모드 그대로**, 심사·사업자 인증 신청 안 함. 관리자 본인 계정의 댓글은 표준 권한(instagram_business_basic, instagram_business_manage_comments)으로 읽을 수 있다.
- 고양이섬과 **같은 Meta 앱 하나**에 드럼용 인스타 계정을 추가해도 된다(계정별 토큰은 따로).
- 막히면: 댓글 확인 없이 "아이디 + 팔로워 암호"만 받는 느슨한 모드로 설정 하나로 전환(`VERIFY_MODE=password`). 지금의 수동 확인(admin "인증 신청자" 탭)은 그대로 남겨 운영자가 언제든 내릴 수 있게.

## 사용자에게 줄 안내 (폰, 한국어)
1. 드럼 인스타를 크리에이터 계정으로. 2. 키티챗 Pro 에 두 번째 계정 연결.
3. 키티챗: 키워드 `쿵-` 포함 댓글 → 모든 게시물 → 버튼 DM → 팔로워: 암호(+링크) / 비팔로워: "팔로우하고 버튼 다시 눌러주세요".
4. Meta 앱에 드럼 계정 연결 → 토큰을 Vercel 환경변수로(채팅에 붙이지 않기). 막히면 화면 캡처.
