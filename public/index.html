    한 칸씩 고치기

    칸을 눌러 켜고 꺼요. 같은 엄지(킥·크래시 / 스네어·하이햇)는 한 칸에 하나만 돼요.

    건반으로 멜로디를 만들어요. 🥁 드럼 탭에서 드럼을 먼저 쳐 두면 녹음할 때 같이 나와요. 멜로디 없이 드럼만 올려도 돼요.

    MIDI(.mid)나 MusicXML(.musicxml·.mxl) 악보 파일을 넣으면 악보의 음·박자 그대로 멜로디·코드·드럼을 만들어요. 파일은 이 폰 밖으로 안 나가요.

    사진·PDF 악보는 악보 스캔 앱(PlayScore 2, MuseScore 의 PDF 가져오기 등)으로 MusicXML 로 바꿔서 넣어요.

    직접 고르기 (모르면 그냥 두세요)

    올린 맵의 저작권 책임은 만든 사람에게 있어요. 권리자 요청이 오면 내려가요.

    폰에 있는 노래(mp3)나 화면 녹화 영상을 넣으면 목소리 멜로디(목소리가 없는 곳은 악기 멜로디)와 코드·드럼까지 노래에서 따요. 파일은 이 폰 밖으로 안 나가요. (처음 한 번 약 30MB 받아요 — 와이파이 추천)

    「녹음」을 누르면 똑딱 소리가 나요. 박자에 맞춰 건반을 치면 그대로 멜로디가 돼요. 박자는 알아서 맞춰 줘요.

      홈 화면에 추가하기

      홈 화면에 아이콘을 만들어 두면 앱처럼 한 번에 들어와요. 주소창 없이 전체 화면으로 더 크게 칠 수 있어요!

      지금은 인스타·카톡 안의 브라우저라 추가가 안 돼요. 오른쪽 위 ⋯ → 외부 브라우저(Safari/Chrome)로 열기를 먼저 눌러 주세요.

      아이폰 (Safari)

      1. 화면 아래 공유 버튼 (네모에 위 화살표 )
      2. 아래로 내려서 홈 화면에 추가
      3. 오른쪽 위 추가

      갤럭시 · 안드로이드

      1. 크롬: 오른쪽 위 ⋮ → 홈 화면에 추가(또는 앱 설치) → 추가
      2. 삼성 인터넷: 아래 ≡ 메뉴 → 현재 페이지 추가 → 홈 화면

      팔로워 인증·기록은 브라우저마다 따로 저장돼요. 아이폰은 홈 화면 아이콘과 사파리가 따로라서, 홈 화면 아이콘으로 열어서 한 번 더 인증해 주세요.

      🚨 주소가 바뀌었어요!

      사람이 너무 많이 와서 예전 서버가 멈췄어요. 그래서 더 튼튼한 새 주소로 이사했어요. 랭킹·점수는 그대로 옮겨 왔어요!

      play.kongkong-drum.workers.dev
      1. 팔로워 인증을 받았던 분 되찾기 요청에 예전 닉네임·인스타 아이디를 적어 보내면 운영자가 찾아서 돌려 드려요.
      2. 그래도 안 찾아지면 되찾기 요청에 예전 닉네임·아이디를 적어 보내 주세요. 운영자가 확인하면 이 폰에서 자동으로 기록이 돌아와요. (사이트에 다시 들어오면 돼요)
      3. 인증 없이 1~3단계만 하던 분 그 기록은 예전 주소를 열던 폰에 남아 있어요. 예전 주소가 다시 열리면, 예전 링크로 한 번만 들어오면 기록이 이 주소로 자동으로 옮겨져요. 1~3단계는 금방 다시 깰 수 있어요!
      4. 폰을 바꿀 땐 ⚙️ 설정 → 다른 폰으로 옮기기에서 숫자 6자리를 받아 새 폰에 넣으면 기록이 그대로 와요.

      📮 기록 되찾기 요청

      예전 계정(기록·코인)을 다시 쓰고 싶으면 적어 주세요. 운영자가 확인하고 맞는 계정을 찾아 드려요. 확인되면 이 폰에서 사이트에 다시 들어올 때 자동으로 돌아와요.

      ✅ 요청을 보냈어요!
      운영자가 확인하면 이 폰에서 사이트에 다시 들어올 때 자동으로 기록이 돌아와요.
